## أسطورة الحالات

| الحالة | المعنى |
|---|---|
| **مكتمل** | جدول + إضافة + عرض + تعديل تعرض وتحفظ/تسترجع الحقول الستة من Client المركزي |
| **ناقص** | سطح يحمل اسم شخص ويفتقد حقول اتصال مطلوبة |
| **غير منطبق** | لا يحمل اسم شخص/موكل/طرف/ضامن، أو الاسم ليس شخصًا (عنوان قالب/قاعدة…) — مع سبب |
